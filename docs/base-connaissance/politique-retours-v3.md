# Politique de retours et échanges — v3 (janvier 2026)

> Maison Orélia est une maison **fictive** créée pour ce dojo.

## Délais
- Retour ou échange : **30 jours** après réception (e-commerce) ou achat (boutique).
- Remboursement sur le moyen de paiement d'origine sous **14 jours** après réception du produit retourné.

## Exclusions
- Parfums et soins **descellés** : aucun retour.
- Pièces personnalisées (monogramme) : aucun retour, réparation uniquement.

## Cas particuliers
- Produit reçu cassé : photo obligatoire sous **48 h**, remplacement sans frais.
- Cadeau : échange uniquement, contre avoir valable 12 mois.
