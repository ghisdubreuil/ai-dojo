# Procédure SAV — réparation maroquinerie

1. La boutique ou le client crée une demande de réparation avec photos.
2. L'atelier évalue sous **5 jours ouvrés** : réparable / non réparable.
3. Devis envoyé si hors garantie. Garantie : **2 ans** sur les défauts de fabrication.
4. Délai moyen de réparation : **6 à 8 semaines**.
5. Si non réparable sous garantie : échange à valeur équivalente validé par le responsable SAV.

## Escalade
- Client mécontent ou valeur > 2 000 € : escalade au responsable SAV sous 24 h.
- Cas VIC (client prioritaire) : réponse sous 4 h ouvrées.
