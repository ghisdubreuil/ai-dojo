# Current process — handling customer care requests (as-is)

> Maison Orélia is fictional. This process is **deliberately manual**: it is the starting point of the Workflow track.

1. A customer writes in (email, chat, phone, social media). An advisor copies the request into a shared spreadsheet.
2. Every morning, a coordinator reads the rows and sorts them by hand: return, exchange, repair, delivery, billing, information.
3. The coordinator decides urgency by gut feeling (words like "URGENT", "gift", "wedding").
4. The request is emailed to an advisor of the right region, and to the relevant workshop for watches and jewelry.
5. The advisor looks up the rule in 4 different documents (some obsolete), then writes the reply by hand.
6. A manager reviews replies for cases above €2,000 or VIC customers.
7. On Fridays, someone counts tickets by type in the spreadsheet for the weekly report.

## Reported pain points
- 2 hours a day spent sorting manually.
- Inconsistent replies between advisors (v2 vs v3 rules).
- No visibility on real response times.
- Weekly report always late.
